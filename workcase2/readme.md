### 2.3
##### У VirtualBox є декілька типів налаштування мережі та підключення Wi-Fi:
- NAT - ВМ доступна до інтернету через NAT від хоста;
- Проміжний адаптер - спеціальний режим для VirtualBox з більшим контролем і можливостями NAT;
- Внутрішня мережа - комунікація тільки між ВМ на одному хості, немає доступу до інтернету;
- Лише головний адаптер - зв'язок тільки між ВМ та хостом, також не має доступу до інтернету;
- Загальний драйвер - використовує спеціальний драйвер ядра для прямого доступу до мережі;
- Мережа NAT - покращена версія NAT з більшою кількістю налаштувань;
- Cloud Network - підключення до хмарних мереж;
- Не під'єднаний - адаптер увімкнений, але не під'єднаний до мережі.
![alt next](https://github.com/Eva-std/Operating-systems/blob/main/workcase2/network2.png?raw=true)

### 2.4
##### У VirtualBox є два основні шляхи для роботи з зовнішніми USB flash-накопичувачами у віртуальній машині (ВМ):
1. Пряме підключення USB-флешки (USB Passthrough)
2. Підключення через спільні папки (Shared Folders)

#### Порівняння GNOME та XFCE:
| Критерії характеристики | GNOME | XFCE |
|-----------|-----------|-----------|
| Споживання ресурсів | ~300-400 МБ ОЗУ | ~100-200 МБ ОЗУ |
| Швидкість роботи | Середня (потребує більше ресурсів) | Дуже швидка |
| Вага   | Важка, сучасна оболонка | Легка оболонка |
| CPU використання | Вище (більше фонових процесів) | Мінімальне |
| Простота користування | Сучасна, інтуїтивна | Традиційна (подібна Windows) |
| Кастомізація | Низька (дизайн-орієнтована) | Висока (багато налаштувань) |
| Панель завдань | Вгорі (сучасна) | Внизу (класична) |
| Меню програм | Сітка додатків | Класичне меню |
| Рівень налаштування | Базовий рівень | Експертний рівень |
