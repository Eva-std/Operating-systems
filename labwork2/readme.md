### 4. Які засоби безпеки використовуються в Linux
##### У Linux використовують декілька засобів безпеки:
- Password Issues:
  -  Складні паролі
  -  Управління користувачами та групами (різні рівні доступу залежно від групи)
  -  Root account (непривілейований акаунт)
  -  Password Manager Programs (програми для зберігання облікових даних у зашифрованому вигляді)
  -  Two-Factor Authentication (2FA)
- Firewall:
  - iptables (вбудована система в Linux)
  - Uncomplicated Firewall (для Ubuntu)
  - Gufw (графічний інтерфейс до UFW)
- Privacy Tools:
  - Encryption
  - HTTPS
  - VPN
  - Tor Browser

### 5. Чому використання віртуалізації зараз стало таким актуальним?
##### Використання віртуальзіції в наш час стало актуальним з декількох причин, а саме: 
- Економія ресурсів, бо декілька ОС можна встановити на одному сервері
- Ізоляція (ВМ не впливають одна на одну)
- Легкість використання (легко створювати, копіювати, видаляти системи)
- Безпека тестування (безпечне тестування ПЗ без ризику Для основної системи)
- Зменшення витрат (віртуалізація потребує менше фізичного обладнання, можна створювати багато ВМ на одному пристрої)
<br>

### 7. Які переваги/недоліки використання програмного забезпечення з відкритим кодом? 
##### Переваги:
1. Вартість - дуже часто ПЗ з відкритим кодом безкоштовні
2. Довготривала та активна підтримка розробниками
3. Відомо, що робить ПЗ
4. Є можливість можифікувати ПЗ під свої потреби
##### Недоліки:
1. Документація часто неповна або застаріла
2. Відсутність комерційної гарантії
3. Можуть бути проблеми з деяким обладнанням
4. Потрібні певні знання для налаштування
<br>

### 8. Скільки активних віртуальних консолей (терміналів) може бути у процесі роботи Linux по замовчуванню. Як їх викликати та між ними перемикатися? Наведіть приклади?
##### За замовчуванням у Linux 6 віртуальних консолей (tty1-tty6 текстові режими, tty7 графічна оболонка). Щоб викликати їх та перемикатися між ними потрібно використовувати наступні комбінації клавіш:
- `Ctrl + Alt + F1` - Для входу в перший віртуальний термінал
- `Ctrl + Alt + F2` - Для входу в другий віртуальний термінал
- `Ctrl + Alt + F3` - Для входу в третій віртуальний термінал
- `Ctrl + Alt + F4` - Для входу в четвертий віртуальний термінал
- `Ctrl + Alt + F5` - Для входу в п'ятий віртуальний термінал
- `Ctrl + Alt + F6` - Для входу в шостий віртуальний термінал
- `Ctrl + Alt + F7` - Для входу в сьомий віртуальний термінал, що повертає до робочого столу Linux
##### Для перших шести терміналів після комбінації клавіш потрібно також ввести ім'я користувача та пароль і лише після цього розпочинати роботу.
<br>

### 9. Яка віртуальна консоль (термінал) виконує функцію графічної оболонки?
##### Функцію графічної оболонки виконує сьома віртуальна консоль (tty7).
<br>

### 10. Чи можлива реєстрація в системі Linux декілька разів під одним і тим же системним ім’ям? Які переваги це може надати?
##### Реєстрація в системі Linux під одним і тим же системним ім'ям можлива, але тоді користувач може входити в систему декілька разва одночасно на різних консолях. 
##### Переваги, які це надає:
1. Одночасне виконання різних завдань
2. Продуктівність, адже не потрібно виходити з системи для переходу в інше середовище
3. Один сеанс не впливає на інший
4. Наявність "резервної консолі", тобто якщо один сеанс зависне, інший буде працювати
