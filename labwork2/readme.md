- Command Line Interface (CLI) - is a simple text input system for entering anything from single-word commands to complicated scripts that that provides a direct way of accessing and controlling the computer.
- GUI Terminal - is a program within the GUI environment that emulates a terminal window. GUI terminals can be accessed through the menu system.
- Virtual Terminal - a terminal that can be run at the same time as a GUI but requires the user to log in via the virtual terminal before they can execute commands
- Server Application - software that has no direct interaction with the monitor and keyboard of the machine it runs on. It's purpose is to serve information to other computers, called clients. 
- Desktop Application - web browsers, text editors, music players, or other applications with which users interact directly. 
- Distribution - a version of Linux that may have different versions of key libraries and software support.

#### 4.1 CLI-режим
##### CLI-режим (режим командного рядка) - простий текстовий режим вводу/виводу, призначений для введення команд, скриптів, тощо.
<br>

#### 4.2 Термінал на основі графічного інтерфейсу користувача 
##### Термінал на совнові графічного інтеріейсу користувача - це програма в середовищі GUI, яка імітує вікно класичного текстового терміналу та зазвичай доступна через систему меню.
<br>

#### 4.3 Віртуальний термінал
##### Віртуальний термінал - це термінал, який може працювати одночасно з GUI, але вимагає від користувача входу через вітруальний тернінал перед виконанням команд. це текстова консоль, яка дозволяють кільком користувачам одночасно виконувати команди на одному комп'ютері Linux, кожен з яких входить в систему окремо, перемикається за допомогою комбінацій клавіш і працює повністю без миші.
