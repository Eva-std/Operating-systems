### Завдання 5 - Дайте відповіді на наступні питання:
#### 5.1 Яку базову інформацію надає рядок запрошення prompt?
##### Зазвичай рядок запрошення надає інформацію про систему та користувача.
<br>

#### 5.2 Для чого команді потрібні параметри та аргументи?
##### Параметри та аргументи потрібні для більшої точності команди та щоб вказувати додаткову інформацію. Аргументи додають додаткову інформацію до команди, а параметри змінюють основну поведінку команди.
<br>

#### 5.3 Яке призначення команд ls, які параметри та аргументи вона може мати? Наведіть 3 приклади. 
##### Команда ls виводить список вмісту каталогу. Вона може мати наступні параметри та аргументи:
- `ls -l` - виводить детальний списик вмісту з додатковою інформацією.
- `ls -r` - виводить вміст поточного каталогу у зворотному порядку
- `ls -l /home` - виводить детальний список батьківсього каталогу
- `ls -l /tmp` - виводить вміст тимчасової директорії
- `ls /etc/ppp` - виводить список файлів і папок у директорії конфігурації РРР-з'єднань
- `ls -lr` - виводить детальний список вмісту поточного каталогу у зворотному порядку
- `ls -rl` - те ж саме, що і -lr
- `ls -lh` - виводить детальний список у форматі, зручному для читання 
<br>

#### 5.4 Яким чином можна використати історію команд, які переваги це надає?
##### Історію команд можна використати декількома способами. А саме: можна не вводити по декілька разів одну і ту саму команду, просто скориставшись історією. Також команди з історії можна редагувати, тобто дописати параметр або аргумент та використовувати як нову команду. Це значно економить час, якщо потрібна команда використовувалась не так давно.
<br>

#### 5.5 Яке призначення команди `echo`?
##### Команда `echo` використовується для виведення текстової інформації в термінал. Працює за майже як `print "***"` у Phyton.
<br>

#### 5.6 Охарактеризуйте поняття змінної в оболонці Bash, які типи змінних вона підтримує? 
##### Змінна - це функція, яка дозволяє користувачу або командній оболонці зберігати дані. Ці дані можуть використовуватися для надання критично важливої системної інформації або для зміни поведінки оболонки Bash. Типи змінник, які вона підтримує:
1. Local (Shell) Variables
   - Існують тільки в поточній оболонці
   - Не можуть впливати на інші команди або додатки
   - Втрачаються при закритті терміналу/оболонки
   - Приклад використання:
```
sysadmin@localhost:~$ variable1='Something'
sysadmin@localhost:~$ echo $variable1
Something
```
2. Environment (Global) Variables
   - Автоматично створюються при відкритті нової оболонки
   - Наслідуються підпроцесами
   - Приклад використання:
```
sysadmin@localhost:~$ HISTSIZE=500
sysadmin@localhost:~$ echo $HISTSIZE
1000
```
<br>

#### 5.7 Яке призначення команд `env`, `export` та `unset`?
##### Команда `env` призначена для виведення списку всіх змінних середовища. `export` - для перетворення локальної змінної на змінну середовища. `unset` - для видалення змінної з пам'яті оболонки.
<br>

#### 5.8 Які команди для отримання довідки по командам в терміналі ви знаєте?
##### Команди для отримання довідки по командам в терміналі:
- `man command` - виводить детальну довідку по команді (від слова manual)
- `whatis command` або `man -f` - пошук за назвою
- `whereis command` - пошук команд, файлів вихідного коду та man pages
- `man -k keyword` або `apropos` - пошук за ключовим словом
- `locate file` - пошук файлів у базі даних
- `info command` - Info Documentation
- `command --help` - швидка допомога по команді
