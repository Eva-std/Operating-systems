### Завдання 1 - В ході роботи досить часто виникає необхідність встановлювати нові програми та додатки. Для цього необхідно в терміналі вміти працювати з менеджерами пакетів:
#### 1.1 Дайте розгорнуте визначення таким поняттям як «пакет» та «репозиторій».
##### Пакет - це архівний файл, який містить усе необхідне для встановлення програми або бібліотеки (виконувані файли, бібліотеки, конфігураційні файли, документацію). Також пакет може містити скрипти, що виконуються до й після встановлення/видалення. Через пакети встановлюються, оновлюються й видаляються програми. Формат пакета залежить від дистрибутива:
- `.deb` - Debian та Ubuntu
- `.rpm` - Red Hat, Fedora, CentOS і openSUSE
- `.pkg.tar.zst` - Arch Linux
##### Репозиторій - це мережеве сховище пакетів з списком пакетів і їхніх метаданих. Менеджер пакетів звертається до репозиторіїв, шукає в них потрібні пакети, перевіряє ключі GPG, завантажує пакети разом із залежностями й встановлює їх. Види репозиторіїв:
- офіційні - основні репозиторії дистрибутива
- дзеркала - копії офіційного репозиторію на інших серверах
- сторонні - репозиторії виробників програм
- локальні - власне сховище в організації чи на диску
<br>

#### 1.2 Надайте короткий огляд існуючих менеджерів пакетів у Linux. Охарактеризуйте їх основні можливості.
##### Менеджери пакетів бувають низькорівневі, які працюють із окремими файлами пакетів, але не вирішують залежності автоматично і високорівневі, що працюють із репозиторіями, шукають, завантажують пакети та їхні залежності

| Менеджер | Дистрибутив | Формат | Основні можливості |
|---|---|---|---|
| `dpkg` | Debian, Ubuntu | `.deb` | низькорівневе встановлення, видалення, перегляд вмісту локальних `.deb`-файлів |
| `apt`/`apt-get` | Debian, Ubuntu, Mint | `.deb` | пошук, встановлення, оновлення, видалення пакетів із репозиторіїв, автоматичне вирішення залежностей |
| `aptitude` | Debian, Ubuntu | `.deb` | альтернативний інтерфейс до APT, інтерактивне текстове меню |
| `rpm` | Red Hat, Fedora, openSUSE | `.rpm` | низькорівневе встановлення та запити до локальної бази пакетів |
| `zypper` | openSUSE, SUSE | `.rpm` | пошук, встановлення, оновлення, керування репозиторіями |
| `pacman` | Arch Linux, Manjaro | `.pkg.tar.zst` | простий і швидкий менеджер, який поєднує встановлення й оновлення системи |
| `apk` | Alpine Linux | `.apk` | легкий менеджер для мінімальних систем |
| `snap` | Ubuntu та інші | `.snap` | універсальні ізольовані пакети з усіма залежностями, автоматичні оновлення |

### Завдання 2 - Визначте який менеджер пакетів використовує ваш дистрибутив Linux. Опишіть основні команди для роботи з ним:
![alt next](https://github.com/Eva-std/Operating-systems/blob/main/workcase4/photos/2.png?raw=true)
#### 2.1 Пошук, скачування та установка необхідних пакетів, яких у Вашій системі немає (зі сховища по замовчуванню, з нового репозиторію тощо).

| Команда | Що виконує |
|---|---|
| `sudo apt update` | оновлює локальний список пакетів із репозиторіїв, виконується перед пошуком і встановленням |
| `apt search слово` | шукає пакети за словом в імені та описі |
| `apt show пакет` | показує докладну інформацію про пакет: версію, розмір, залежності, опис |
| `apt policy пакет` | показує встановлену й доступну версії та репозиторій, звідки пакет |
| `sudo apt install пакет` | завантажує пакет разом із залежностями й встановлює його |
| `sudo apt install -y пакет` | те саме без запиту підтвердження |
| `apt download пакет` | лише завантажує `.deb`-файл пакета в поточний каталог, не встановлюючи його |
##### Установка з нового репозиторію (PPA):
> я розписала для встановлення версій Python
```
sudo apt install software-properties-common
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.12
```
##### Додавання стороннього репозиторію вручну:
1. Завантажити GPG-ключ репозиторію та зберегти його
2. Створити файл `/etc/apt/sources.list.d/назва.list` із рядком `deb [signed-by=/etc/apt/keyrings/ключ.gpg] https://адреса_репозиторію дистрибутив компонент`
3. Виконати `sudo apt update` і встановити потрібний пакет
<br>

#### 2.2 Перегляд інформації про встановлені та доступні пакети
- `apt list --installed` - виводить список усіх встановлених пакетів 
- `apt list --upgradable` - виводить пакети, для яких є нові версії 
- `apt list пакет` - перевіряє, чи є пакет у репозиторіях та чи встановлений він 
- `dpkg -l` - список встановлених пакетів (з версіями і описом) 
- `dpkg -l \| grep слово` - пошук серед встановлених пакетів 
- `dpkg -L пакет` - показує файли, які встановив пакет 
- `dpkg -S /шлях/до/файлу` - показує, якому пакету належить файл 
- `apt show пакет` - показує доступний чи встановлений пакет
<br>

#### 2.3 Видалення непотрібних або застарілих пакетів.
- `sudo apt remove пакет` - видаляє пакет, але залишає його файли конфігурації 
- `sudo apt purge пакет` - видаляє пакет разом із файлами конфігурації 
- `sudo apt autoremove` - видаляє пакети, які були встановлені як залежності й більше не потрібні 
- `sudo apt autoremove --purge` - те саме разом із конфігураціями 
- `sudo apt clean` - очищує кеш завантажених `.deb`-файлів 
- `sudo apt autoclean` - видаляє з кешу лише застарілі версії пакетів 
<br>

#### 2.4 Оновлення менеджера пакетів
- `sudo apt update` - оновлює списки пакетів з репозиторіїв 
- `sudo apt upgrade` - оновлює встановлені пакети до нових версій, не видаляючи інші пакети
- `sudo apt full-upgrade` - оновлює всі пакети, у разі потреби видаляє/додаючє залежності 
- `sudo apt install --only-upgrade apt` - оновлює сам менеджер пакетів APT
- `sudo apt install --only-upgrade пакет` - оновлює лише вказаний пакет 
- `sudo do-release-upgrade` - оновлення Ubuntu до наступної версії дистрибутива

### Завдання 4 - Яким чином можна встановити нові програми через магазини додатків та менеджери пакетів у графічному середовищі. Наведіть свої приклади.
#### 4.1 Магазин додатків Ubuntu
##### Приклад (встановлення VLC):
1. Відкрити App Center
2. У рядку пошуку ввести "VLC"
3. Відкрити сторінку програми й натиснути "Install"
4. Ввести пароль користувача для підтвердження
<br>

#### 4.2 Графічний менеджер пакетів Synaptic
##### Приклад:
1. Запустити Synaptic Package Manager
2. Натиснути "Reload" для оновлення списку пакетів
3. Знайти пакет через "Search" 
4. Клацнути на пакет ПКМ і вибрати "Mark for Installation"
5. Натиснути "Apply", потім ще раз у вікні підтвердження
<br>

#### 4.3 Інші способи
##### Встановлення завантаженого `.deb`-файлу подвійним клацанням або командою `sudo apt install ./файл.deb`. Discover - графічний магазин середовища KDE (Kubuntu). GNOME Software - магазин у багатьох дистрибутивах із середовищем GNOME.
