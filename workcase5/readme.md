### Завдання 1 - При роботі з персональним комп’ютером дуже часто виникає необхідність підключати периферійне обладнання. На прикладі принтера та флешки опишіть який механізм має ОС Linux для роботи з ними.
##### Флешка 
- USB-пристрої можна підключати й відключати під час роботи системи
- Після підключення ядро створює файл блокового пристрою, наприклад `/dev/sdb`, а для розділу на ньому - `/dev/sdb1`
- Щоб працювати з файлами на флешці, її файлову систему потрібно змонтувати. У GUI це відбувається автоматично, і флешка з'являється у файловому менеджері; у терміналі зазвичай монтують вручну за допомогою команди `mount`
- Перед відключенням флешку розмонтовують командою `umount` або кнопкою "Витягти" в файловому менеджері. Якщо цього не зробити, то через ієрархію процесів, процес копіювання/переміщення чи будь-яких інших операцій може не завершитись, а файли пошкодитись

##### Принтер
Друком у Linux керує система CUPS (Common Unix Printing System)
- приймає завдання від програм і користувачів і ставить їх у чергу друку
- використовує драйвер для перетворення документа у формат, зрозумілий принтеру
- надсилає завдання на принтер 
##### Керувати принтерами можна через графічні налаштування (Параметри -> Принтери) або командами:
- `lpstat -p -d` - показує встановлені принтери та принтер за замовчуванням 
- `lpinfo -v` - показує принтери, які бачить система 
- `sudo lpadmin -p Name -E -v URI -m everywhere` - додає принтер з іменем заданим ім'ям
- `lpoptions -d Name` - встановлює принтер за замовчуванням 
- `lp файл` (`lp -d Name файл`) - відправляє файл на друк 
- `lpq` - показує чергу друку 
- `lprm номер_завдання` - скасовує завдання друку 
<br>

#### 1.1 В чому суть операції монтування, для чого вона використовується та як?
> суть монтування я описала у минулому пункті в розділі з флешкою
##### Виконати монтування можно графічно (описано вище), а можна за допомогою команд:
- `sudo mkdir -p /mnt/usb` - створити точку монтування
- `sudo mount /dev/sdb1 /mnt/usb` - змонтувати 
- `sudo umount /mnt/usb` - розмонтувати
<br>

#### 1.2 В чому різниця при роботі з периферією у ОС Linux та ОС Windows?
| Ознака | Linux | Windows |
|---|---|---|
| Представлення пристроїв | файли пристроїв у `/dev`, усе є файлом | літери дисків (C, D), пристрої в диспетчері пристроїв |
| Доступ до диска | файлову систему потрібно змонтувати в каталог єдиного дерева (`/media`, `/mnt`) | диск автоматично отримує літеру |
| Драйвери | велика частина вбудована в ядро або завантажується як модулі | їх зазвичай постачає виробник і встановлюются вони окремо |
| Друк | система CUPS, графічні параметри або команди `lp`, `lpstat` | служба друку Windows (Print Spooler), драйвер виробника |
| Безпечне відключення | `umount` або "Витягти" | "Безпечне вилучення пристрою" |
| Файлові системи | ext4, XFS, Btrfs та інші; NTFS, FAT32, exFAT підтримуються | NTFS, FAT32, exFAT; ext4 без додаткових програм не підтримується |
| Права доступу | дії типу `mount` потребують прав адміністратора (`sudo`), доступ до файлів керується правами | керується правами облікового запису та політиками |
| Керування | графічно і повністю з командного рядка | переважно графічно |

## Висновки
While completing workcase 5, I learned how Linux works with peripheral devices, which are represented as files in the `/dev` directory and served by drivers and kernel modules. I studied the mounting operation, which attaches the file system of a usb flash drive to the directory tree, and the CUPS printing system. I compared working with peripherals in Linux and Windows and described how to connect a USB flash drive and a printer to a virtual machine, copy a file from the flash drive and print it both in the graphical interface and with the `mount`, `cp`, `lp` and `umount` commands.
